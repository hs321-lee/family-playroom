## 실행 및 배포

브라우저에서 `index.html`을 엽니다. 마이크를 쓰려면 HTTPS에서 제공하거나 로컬 서버로 실행합니다.

```sh
python3 -m http.server 8000
```

GitHub Pages를 쓰는 경우 `index.html`을 공개 소스 브랜치 루트에 올리고 해당 브랜치의 루트를 게시합니다. 커스텀 도메인은 GitHub Pages의 도메인 설정에서 연결할 수 있습니다.

## 브리핑 운영

매주 목요일 저녁 나들이 추천 자동화가 공개 장소 정보를 `outings/YYYY-MM.json`에 갱신합니다. 사이트는 선택한 주간·월간 범위의 월별 파일을 읽습니다. 수동으로 저장한 브리핑은 해당 브라우저에서 같은 발행일의 공개 브리핑보다 우선 표시합니다. 서울 시간 기준으로 주간은 월요일부터 일요일까지, 월간은 달력 월 단위로 발행일을 묶습니다. 가족 일정은 방문일 기준으로 표시합니다.

```json
{
  "date": "2026-11-26",
  "weather": "주말 날씨 요약",
  "items": [
    {
      "title": "활동 이름",
      "area": "지역",
      "type": "실내",
      "pick": "최우선 추천",
      "address": "장소 주소",
      "travel": "예상 이동 시간",
      "visitDate": "2026-11-28",
      "time": "10:30",
      "cost": "가족 예상 비용",
      "booking": "예약 상태",
      "note": "추천 이유",
      "url": "https://example.com/"
    }
  ]
}
```

공개 브리핑 파일은 `{"version":1,"briefings":[...]}` 형식이며, 배열에는 위 형식의 브리핑을 발행일로 구분해 저장합니다. 날씨 출처는 선택 필드 `weatherUrl`로 넣을 수 있습니다. 가족 일정과 수동으로 저장한 브리핑은 브라우저 저장 공간에, 목소리는 그 브라우저의 IndexedDB에 보관합니다. 마이크 녹음은 버튼을 눌러 시작하며 최대 6초입니다. 기본 발음 재생에는 브라우저에서 제공하는 기기 내 한국어 음성이 필요합니다.

도메인을 바꾸면 브라우저 저장 공간도 달라지므로 실제 전환 전에 데이터 내보내기와 가져오기를 추가합니다.

아침·저녁 할 일 보상은 한국 시간 기준으로 하루에 각 한 번씩 쌓입니다. 부모 메뉴에서 추가한 보상 사진과 할 일 기록은 사용하는 브라우저에 저장합니다.

놀이터 별명, 배움놀이에서 모은 별, 완성한 동물은 사용하는 브라우저에서 이어집니다.
