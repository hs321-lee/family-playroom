# 우리집 놀이터

유아 한글놀이·미술놀이와 가족 일정·나들이 브리핑을 한곳에서 쓰는 정적 웹 앱입니다.

| 화면 | 기능 |
| --- | --- |
| 한글놀이 | 낱말 카드 24개, 자음·모음 조합 20개, 첫 글자, 낱말별 직접 녹음·재생·삭제 |
| 숫자놀이 | 1–10 수 세기, 20까지 빠진 숫자, 합이 10 이하인 더하기 |
| 영어놀이 | 알파벳 대·소문자, 그림 단어 20개, 첫 알파벳 |
| EBS 영상 | EBS 키즈·EBS ENGLISH의 한글·수학·파닉스 영상 링크 |
| 미술놀이 | 동물 15종 네온 따라 그리기, 완성 애니메이션, 자유 그리기와 PNG 저장 |
| 가족 대시보드 | 주간·월간 보기, 가족 일정 추가·수정·삭제, 나들이 브리핑 가져오기, 브리핑에서 일정 만들기 |
| 오늘 할 일 | 아침·저녁 체크리스트, 날짜별 완료 기록, 부모 메뉴에서 선택한 보상 사진 |

## 실행 및 배포

브라우저에서 `index.html`을 엽니다. 마이크를 쓰려면 HTTPS에서 제공하거나 로컬 서버로 실행합니다.

```sh
python3 -m http.server 8000
```

GitHub Pages를 쓰는 경우 `index.html`을 공개 소스 브랜치 루트에 올리고 해당 브랜치의 루트를 게시합니다. 커스텀 도메인은 GitHub Pages의 도메인 설정에서 연결할 수 있습니다.

## 브리핑 운영

현재 나들이 브리핑은 ChatGPT에서 받은 내용을 JSON으로 변환해 가족 대시보드의 **나들이 브리핑 → 브리핑 가져오기**에 저장합니다. 같은 발행일로 다시 저장하면 해당 호를 갱신합니다. 서울 시간 기준으로 주간은 월요일부터 일요일까지, 월간은 달력 월 단위로 발행일을 묶습니다. 가족 일정은 방문일 기준으로 표시합니다.

```json
{
  "date": "2026-11-26",
  "weather": "주말 날씨 요약",
  "items": [
    {
      "title": "활동 이름",
      "area": "지역",
      "type": "실내",
      "pick": "최우선 추천",
      "address": "장소 주소",
      "travel": "예상 이동 시간",
      "visitDate": "2026-11-28",
      "time": "10:30",
      "cost": "가족 예상 비용",
      "booking": "예약 상태",
      "note": "추천 이유",
      "url": "https://example.com/"
    }
  ]
}
```

날씨와 장소 정보는 가져온 브리핑에 따릅니다. 가족 일정과 브리핑 데이터는 브라우저 저장 공간에, 목소리는 그 브라우저의 IndexedDB에 보관합니다. 마이크 녹음은 버튼을 눌러 시작하며 최대 6초입니다. 기본 발음 재생에는 브라우저에서 제공하는 기기 내 한국어 음성이 필요합니다.

다음 단계에서는 부모 계정으로 접근하는 공동 일정을 연결하고, 기존 주말 추천이 발행될 때 가족만 볼 수 있는 브리핑 탭으로 전달할 수 있습니다. 도메인을 바꾸면 브라우저 저장 공간도 달라지므로 실제 전환 전에 데이터 내보내기와 가져오기를 추가합니다.

아침·저녁 할 일 보상은 한국 시간 기준으로 하루에 각 한 번씩 쌓입니다. 부모 메뉴에서 추가한 보상 사진과 할 일 기록은 사용하는 브라우저에 저장합니다.

놀이터 별명, 배움놀이에서 모은 별, 완성한 동물은 사용하는 브라우저에서 이어집니다.
